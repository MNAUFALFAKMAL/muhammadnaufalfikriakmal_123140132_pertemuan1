# Folder Screenshot

Simpan tangkapan layar (screenshot) aplikasi yang sudah berjalan dengan nama:

```text
screenshot.png
```

Cara membuat screenshot:

1. Jalankan aplikasi via **Live Server** di VS Code.
2. Pastikan halaman sudah memuat tugas, kutipan, dan cuaca.
3. Tekan **PrtScr** / gunakan Snipping Tool, lalu simpan file-nya di folder ini sebagai `screenshot.png`.

Setelah itu, gambar akan otomatis tampil di `README.md` bagian "Screenshot Antarmuka".
